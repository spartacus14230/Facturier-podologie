📅 Google — Agenda & Envoi d'emails

Pour activer la synchronisation avec Google Agenda et l'envoi automatique de factures par email (avec PDF joint), vous devez créer un Client ID Google (gratuit). → Google Cloud Console
📖 Guide de configuration (5 min)
  1. Aller sur console.cloud.google.com
  2. Créer un nouveau projet (ex: "FW Podologue")
  3. Aller dans API et services → Bibliothèque
  4. Chercher "Google Calendar API" et l'activer
  5. Chercher aussi "Gmail API" et l'activer (pour l'envoi de factures par email)
  6. Aller dans API et services → Identifiants
  7. Cliquer Créer des identifiants → ID client OAuth
  8. Type: Application Web
  9. Origines JS autorisées: ajouter l'URL de votre appli (ex: https://votre-domaine.com ou http://localhost)
  10. Copier le Client ID et le coller ci-dessous
  11. Dans Écran de consentement OAuth: ajouter votre email comme utilisateur test

📧 Envoi factures — Email + SMS

✅ Envoi automatique via Gmail (gratuit & illimité)

L'envoi de factures utilise la même connexion Google que l'Agenda.
→ Le PDF est joint automatiquement à l'email
→ Vous recevez une copie en BCC dans votre boîte mail
→ Le SMS est proposé automatiquement après l'envoi

Pré-requis :
1. Le Client ID Google doit être configuré (section Google Agenda ci-dessus)
2. Dans la Google Cloud Console, activez l'API "Gmail API" (en plus de Calendar)
3. Connectez-vous via le bouton "Connecter Google Agenda" sur la page Agenda
4. Lors de la connexion, acceptez les permissions Gmail qui s'affichent
